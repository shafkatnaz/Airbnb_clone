# Wanderlust

A full-stack Airbnb-inspired web application built using Node.js,
Express.js, MongoDB and EJS.

## Live Demo

https://majorproject-c2kc.onrender.com

## Features

- User registration and login
- Authentication
- Email verification
- Password reset
- Create listings
- Edit listings
- Delete listings
- Reviews and ratings
- Search
- Category filtering
- Pagination
- Image uploads
- MongoDB Atlas database
- Responsive UI

## Tech Stack

Frontend:
- HTML
- CSS
- Bootstrap
- JavaScript
- EJS

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose

Authentication:
- Passport.js
- Passport Local

Deployment:
- Render
- MongoDB Atlas
